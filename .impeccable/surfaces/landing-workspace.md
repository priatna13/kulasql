# Surface: landing + workspace (tiket 01)

Mode: Persuade di `/kulasql` (dan hero `/` bila sama), Operate di `/kulasql/challenges/:slug`. Satu dunia, dua densitas.

## Direction contract

**THESIS:** Buktikan “nulis query” di viewport pertama — editor hidup, bukan brochure. Tolak hero mockup + landing siang.

**OWN-WORLD:** Kos malam, satu layar. Netral malam; aksen hanya Run/Sempurna/XP; lampu kamar atmosfer tipis. Daftar bukan kartu. Wordmark, bukan maskot.

**STORY:** Tamu paham ini latihan SQL di browser, mengetik di soal TokoKulwon, menekan Mulai Tantangan Gratis atau langsung Run.

**FIRST VIEWPORT (desktop):** strip satu baris (logo · nav kapsul · Masuk). Di bawahnya headline “Bisa SQL dari nulis query” + CTA primer dekat kerangka: rel kiri prompt+skema, editor tengah, zona hasil tenang sampai Run. Social proof dan tiga jalur di bawah lipatan.

**FIRST VIEWPORT (mobile):** strip ringkas, headline, CTA, prompt terbaca. Tidak ada editor hidup. Copy jujur: latihan di laptop.

**FORM:** instrumen yang sama di marketing dan soal; densitas landing sedikit lebih longgar. Seed visual: keputusan grill 1–13. (concept-seed Impeccable tidak jalan — engine Windows checksum gagal.)

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Signature interaction

Satu gerak yang diingat: Run Query → panel hasil hadir di bawah editor. Submit lulus = cap Sempurna + XP, lalu editor raja lagi. Error di zona hasil, bukan modal. Tanpa partikel, bounce, atau transisi halaman teatrikal.

## Boundaries

Tidak di permukaan ini: checkout, banner premium, mockup laptop, editor mini di HP, ornamen lokal, confetti. Klaim traction hanya jika dilabeli kutipan marketing.
